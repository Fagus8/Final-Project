# medical.ge

ექიმთან ვიზიტის ონლაინ დაჯავშნის საიტი. პაციენტი პოულობს ექიმს და თავისუფალ დროზე ჯავშნის ვიზიტს, ექიმი მართავს განრიგს და წერს დიაგნოზს, კლინიკა კი მართავს თავის ექიმებსა და ვიზიტებს.

## შესაძლებლობები

| როლი | რა შეუძლია |
| --- | --- |
| პაციენტი | ექიმის ძებნა, ვიზიტის დაჯავშნა და გაუქმება, დიაგნოზებისა და დანიშნულებების ნახვა |
| ექიმი | კლინიკასთან შეერთება, სამუშაო საათების მართვა, დიაგნოზისა და დანიშნულების ჩაწერა |
| კლინიკა | ექიმების დადასტურება და მართვა, ვიზიტების ნახვა |
| ადმინისტრატორი | ახალი კლინიკების დამტკიცება, პაციენტების სია |

## ტექნოლოგიები

Next.js 16 · React 19 · TypeScript · PostgreSQL · Prisma 7 · Better Auth · Formik და Zod · SCSS მოდულები · Swagger (API დოკუმენტაცია) · Vitest (ტესტები)

## გაშვება

საჭიროა **Node.js** და **PostgreSQL**.

1. დააყენე პაკეტები:

   ```bash
   npm install
   ```

2. პროექტის საქაღალდეში შექმენი `.env` ფაილი:

   ```env
   DATABASE_URL="postgresql://USER:PASSWORD@localhost:5432/DATABASE"
   BETTER_AUTH_SECRET="ნებისმიერი გრძელი შემთხვევითი სტრიქონი"
   ```

   `.env` Git-ში არ იტვირთება, ამიტომ თითოეულ კომპიუტერზე ცალკე იქმნება.

3. შექმენი ბაზის ცხრილები და სადემონსტრაციო მონაცემები:

   ```bash
   npx prisma migrate dev
   npx prisma db seed
   ```

4. გაუშვი საიტი და გახსენი [http://localhost:3000](http://localhost:3000):

   ```bash
   npm run dev
   ```

## სტრუქტურა

```text
prisma/
  schema.prisma     ბაზის სქემა
  migrations/       ბაზის ცვლილებები
  seed.ts           სადემონსტრაციო მონაცემები
src/
  app/              გვერდები და API (route-ები)
  components/       რამდენიმე გვერდზე გამოყენებული კომპონენტები
  lib/              სერვერის ლოგიკა: ავტორიზაცია, ბაზა, დროის სლოტები
  styles/           საერთო სტილები და ფერები
```

`src/app`-ში ფრჩხილებიანი საქაღალდეები, მაგალითად `(patient)` და `(staff)`, გვერდებს როლების მიხედვით აჯგუფებს. ეს სახელები მისამართში არ ჩანს: `src/app/(patient)/booking` გვერდის მისამართია `/booking`.
